# Hoverboard-robot project

## Project description

This project has been forked from a well known repository [hoverboard-firmware-hack-FOC](https://github.com/EFeru/hoverboard-firmware-hack-FOC).
The goal of this project is to create a simple and cheap mobile robot platform compatible with ROS2 based on Hoverboard hardware.

## Agents guidelines
- All the comments, logs and variable names must be in English, no other languages allowed.
- Ask for confermation before making any not read-only git action.
- Ask for confermation before trying to flash code on any external device.
- Keep comments inside code short and usefull for any new user. No historical comments describing changes w.r.t. old code versions.
